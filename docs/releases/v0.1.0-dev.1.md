# Porchlight 0.1.0 — Development Preview 1

Porchlight is a free, MIT-licensed Blink camera companion that runs on your Windows PC. Save available recordings locally, browse them from your PC or phone, and optionally add local AI descriptions, reviewed face-match suggestions and phone notifications.

This is the **first development preview**, intended for early users willing to follow source-install instructions and report issues. It is not a packaged Windows installer or a universal Blink compatibility guarantee. Porchlight is independent of Amazon and Blink.

## Start here

1. Download the **Source code (zip)** below and extract it outside OneDrive, or clone this release:

   ```powershell
   git clone --branch v0.1.0-dev.1 https://github.com/kevindemara/Porchlight.git
   Set-Location Porchlight
   ```

2. Follow the [Windows installation guide](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/QUICK_START.md). Install Python 3.12–3.14 and supported Node.js 22.12 or newer with npm. Use a PowerShell environment that permits reviewed local scripts.
3. From the extracted/cloned source folder, run:

   ```powershell
   .\setup.ps1 -Check
   .\setup.ps1
   .\start.ps1
   ```

   Setup asks before installing locked packages and separately offers FFmpeg/ffprobe for media processing. No models or remote-access services are installed automatically.

4. Leave the app terminal running and open **http://127.0.0.1:8765 on the PC**. Create your local owner, connect Blink through the local form, explicitly enable an available recording source and confirm a new clip saves and plays. Choose **Use Porchlight without AI** if desired.

Read the [README](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/README.md) for the complete workflow. Keep the PC awake and the app running for new imports, analysis, phone access and alerts. Normal source setup does not register automatic startup.

## Included

- Automatic archiving of available Blink cloud clips, durable discovery, deduplication and bounded recovery from temporary failures.
- Activity with saved recordings and snapshots, protected playback, search, favourites, notes and local export.
- Optional local Ollama descriptions and opt-in SFace face-match suggestions for names you review. The archive works with AI disabled.
- Android home-screen installation and optional Web Push with descriptions, conservative saved-name updates, protected thumbnails and links to the matching recording.
- Supported bounded live viewing, supplied audio when available, Record, Snapshot and camera controls with remote-state confirmation.
- Storage settings, diagnostics and backup/restore tooling.

## Phone setup

The phone connects to the app on your PC through a separately configured trusted HTTPS address. [Direct home HTTPS](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/DIRECT_HTTPS.md) is a tested option when the home internet/router supports it; [Cloudflare private access](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/CLOUDFLARE_BACKUP.md) is an optional backup requiring an enrolled phone client. Neither route is enabled automatically.

Follow [phone setup](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/PHONE_SETUP.md) and [Web Push setup](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/WEB_PUSH.md). The PC's `127.0.0.1` address does not connect a phone to the PC. Installing a home-screen icon alone does not enable notifications or offline playback.

## Validation and limitations

- Real paid-cloud archiving, local AI review and Android integration have been exercised. The owner reports completing fresh backup/isolated restore, a 24–48-hour soak with automatic recovery/sleep/network checks, the listed locked/closed-app Wi-Fi/cellular phone checks and new-user Windows setup. These results cover the tested setup; they are not independent certification of every device or environment.
- **Subscription-free Sync Module recording retrieval is experimental and unverified.** Paid-plan card backups are different from direct local recordings. Do not cancel a Blink plan based on this preview. Camera/module/account capabilities determine which sources are actually available.
- New Blink retrieval depends on Blink's internet services. Porchlight is not an offline Blink replacement or a continuous recorder. Two-way talk is not supported.
- AI and face matches can be wrong; review original recordings. Notifications can start generic and receive quiet updates later; timing and image display vary by Android/browser and connectivity.
- Windows is the supported host. Android Chrome is the tested phone path; iOS and other browsers are not verified. PowerShell script restrictions still apply; no signed installer is included.
- Private clips, credentials, network settings, certificates, models and FFmpeg executables are not release assets. AI runs locally; optional push and remote-access routes use the third-party services described in their guides.

See [known limitations](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/KNOWN_LIMITATIONS.md) and [release evidence](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/RELEASE_AUDIT.md). Hosted CI was previously blocked by GitHub account infrastructure; it is not claimed as passing release evidence. Local automated results and owner-reported acceptance are documented separately.

## Updating and reporting issues

Before updating an existing installation, stop Porchlight, create a fresh private backup and follow [Update safely](https://github.com/kevindemara/Porchlight/blob/v0.1.0-dev.1/docs/QUICK_START.md#update-safely). Never overwrite your active profile with a restore.

Report problems through [GitHub Issues](https://github.com/kevindemara/Porchlight/issues) with versions, reproduction steps and redacted error codes. Exclude recordings, face samples, databases, credentials, keys and unredacted diagnostics.
